# 블록 월드

폰 가로 화면에서 즐기는 3D 블록 샌드박스 게임입니다. (Three.js + Vite + TypeScript)

## 실행

```
npm install
npm run dev -- --host    # 개발 서버 (같은 와이파이의 폰에서 http://컴퓨터IP:5190/ 로 접속)
npm test                 # 규칙 테스트
npm run build            # 배포용 빌드 (dist 폴더)
```

## 조작

| 터치 | 키보드 |
| --- | --- |
| 화면 왼쪽을 누른 채 끌기: 이동 | WASD |
| 화면 오른쪽을 끌기: 둘러보기 | 마우스로 화면 오른쪽 끌기 |
| 점프 / 부수기 / 놓기 버튼 (꾹 누르면 반복) | 스페이스 / Q / E |
| 아이템 바 칸 누르기 | 1~6 |
| 가방 버튼 | B |

## 게임 내용

- 256×256 월드, 초원·숲·사막·눈밭, 바다와 동굴, 땅속 철광석과 (더 깊고 훨씬 드문) 다이아몬드
- 낮과 밤(4분에 한 바퀴). 밤에는 좀비가 나오고, 침대에서 자면 아침이 됩니다.
- 서바이벌(블록을 모아서 사용) / 창작(블록 무한, 점프 두 번 빠르게 누르면 비행) 방식. 가방 화면에서 바꿀 수 있습니다.
- 제작: 판자·막대·제작대(가방), 제작대에서 곡괭이·도끼·삽·검(나무·돌·철·다이아몬드, 쓸수록 닳음)·갑옷(철·다이아몬드, 가진 것 중 가장 좋은 걸 자동으로 걸쳐요)·활과 화살(가까이 못 가는 동물·괴물을 부수기 버튼으로 자동으로 쏴요)·화로·침대·빵, 화로에서 철 주괴·유리·구운 고기
- 가방은 27칸, 한 칸에 64개까지 쌓여요(도구·갑옷·활은 칸마다 1개). 가방이 다 차면 더 줍거나 만들 수 없어요.
- 블록을 캐거나 동물을 잡으면 바닥에 떨어졌다가 가까이 가면 주워요
- 돼지, 양(고기·양털), 좀비, 해골(원거리 화살), 크리퍼(가까이 오면 몇 초 뒤 폭발), 거미(좀비보다 빠름), 물고기(바다에서만, 잡아서 구워 먹음), 늑대(뼈로 길들이면 따라다니며 대신 싸움), 꽃, 밀 농사, 도전 과제 24개
- 횃불(막대+나무): 낮밤·동굴과 상관없이 주변을 계속 밝혀요. 벽으로 막으면 못 넘어가고, 나중에 뚫으면 다시 들어와요.
- 배고픔 게이지: 걷거나 시간이 지나면 줄고, 다 떨어지면 체력이 서서히 깎여요(1까지만). 음식으로 채우고, 가득 차야 체력이 저절로 회복돼요.
- 자동 저장 (브라우저 localStorage), 배경음악과 효과음(코드로 합성)
- 폰 성능에 맞춰 화질을 스스로 낮춥니다. 주소 끝에 `?quality=0`~`3`을 붙이면 고정됩니다.
- **멀티플레이(최대 4명)**: 화면 위 "함께" 버튼으로 지금 세상을 열고, 생긴 방 코드나 주소를 친구에게 보내면 같은 세상에서 만나요. 서로 움직이는 모습이 보이고, 블록을 캐거나 놓으면 다 같이 보여요. (동물·몬스터, 가방, 체력·배고픔은 각자 것이에요 — 아래 "한계" 참고)

### 멀티플레이 한계 (지금은 이렇게 단순화했어요)

- 같이 보이는 건 **서로의 위치와 블록 변화**뿐이에요. 동물·몬스터, 떨어진 아이템, 화로·농사 진행 상태는 각자 화면에서 따로 움직여요.
- 방 안 아무나 뼈로 늑대를 길들이거나 화로를 써도, 그 결과(길들인 늑대, 화로 속 내용물)는 그 사람 화면에만 보여요.
- 인터넷 연결이 필요해요(같은 와이파이가 아니어도 됩니다). 연결이 끊기면 자동으로 혼자 하기로 돌아가요.

## 개발용 주소 옵션

- `?seed=숫자` 같은 지형으로 시작
- `?time=0.5` 시간을 멈춤 (0 한밤중, 0.25 해 뜸, 0.5 한낮, 0.75 해 짐)
- `?debug` 콘솔에서 `__vox`로 월드·플레이어·가방 등을 만질 수 있음
- `?room=방코드` 그 방에 바로 들어가기 (친구가 "함께" 버튼으로 만든 주소를 그대로 열면 됨)
- `?party=주소` 멀티플레이 서버를 다른 곳으로 지정 (개발 중 `npm run party:dev`로 띄운 로컬 서버를 쓰려면 `?party=127.0.0.1:1999`)

## 구조

```
src/
  world.ts      블록 종류, 지형·동굴·광석·꽃 생성, 횃불빛 계산(빛 퍼뜨리기·거둬들이기)
  mesher.ts     구역(chunk)을 그림 조각으로 만들기 (횃불빛 닿는 면은 낮밤 안 타는 별도 재질), atlas.ts 블록 무늬(코드로 그림)
  chunks.ts     플레이어 주변 구역만 그리기, chunkMath.ts 구역 계산
  player.ts     이동·중력·수영·자동 점프, raycast.ts 조준
  mobs.ts       돼지·양·좀비·해골·크리퍼·거미·물고기·늑대 움직임, mobRender.ts 모양 그리기
  health.ts     체력·낙하 피해, hunger.ts 배고픔, inventory.ts 가방·제작 규칙·드롭
  drops.ts      바닥에 떨어진 아이템, furnace.ts 화로 굽기
  crops.ts      농사, achievements.ts 도전 과제, daycycle.ts 낮밤
  audio.ts      효과음 합성, music.ts 배경음악 작곡
  quality.ts    자동 화질 조절, save.ts 저장 형식
  controls.ts   터치·키보드 입력, main.ts 모든 것을 잇는 곳
  protocol.ts   멀티플레이 메시지 모양(순수 로직), net.ts 서버 접속, playerRender.ts 다른 사람 아바타
party/
  server.ts     멀티플레이 서버 (PartyKit). 방마다 시드와 블록 변화를 기억했다가 새로 들어온 사람에게 알려줌
```

게임 규칙 파일(`*.ts`, 화면과 무관한 것)은 `*.test.ts`로 테스트합니다.

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml`이 준비되어 있습니다. GitHub에 새 저장소를 만들어 올리면
`master`에 push할 때마다 테스트 → 빌드 → Pages 배포가 자동으로 실행됩니다.
저장소 Settings → Pages → Source를 "GitHub Actions"로 바꿔 주세요.

## 배포 (멀티플레이 서버, PartyKit)

멀티플레이는 GitHub Pages(정적 파일)와 별도로, 실시간으로 메시지를 주고받는 작은 서버가 하나 더 필요합니다.
[PartyKit](https://www.partykit.io/)이라는 무료 서비스(Cloudflare 기반)를 씁니다.

```
npx partykit login    # 처음 한 번, 브라우저로 로그인
npm run party:deploy  # party/server.ts를 배포 (voxelgame.내계정.partykit.dev 같은 주소가 나옵니다)
```

배포된 주소가 나오면 `src/main.ts`에서 `PARTY_HOST_DEFAULT` 값을 그 주소로 바꾸고 다시 `npm run build`(또는 GitHub Pages는 push)하면
"함께" 버튼이 그 서버를 쓰게 됩니다. 개발 중에는 `npm run party:dev`로 컴퓨터에서 서버를 띄우고 주소 끝에
`?party=127.0.0.1:1999`를 붙이면 배포 없이 테스트할 수 있습니다.

같은 방에 최대 4명까지 들어갈 수 있고, 방의 블록 변화는 서버에 저장되어 다시 들어와도 남아 있습니다.

## 앱처럼 설치하기 (PWA)

배포된 주소에서 브라우저 메뉴의 "홈 화면에 추가"(아이폰은 공유 → 홈 화면에 추가)를 누르면
주소창 없이 가로 전체 화면으로 열립니다. 처음 접속하면 게임 파일이 폰에 저장되어 인터넷이 없어도 열립니다.
(`public/manifest.webmanifest`, `public/sw.js`, 아이콘은 `public/`에 있습니다. 개발 서버에서는 동작하지 않고 배포본에서만 동작합니다.)

# 블록 월드

폰 가로 화면에서 즐기는 3D 블록 샌드박스 게임입니다. (Three.js + Vite + TypeScript)

## 실행

```
npm install
npm run dev -- --host    # 개발 서버 (같은 와이파이의 폰에서 http://컴퓨터IP:5190/ 로 접속)
npm test                 # 규칙 테스트
npm run build            # 배포용 빌드 (dist 폴더)
```

## 조작

| 터치 | 키보드 |
| --- | --- |
| 화면 왼쪽을 누른 채 끌기: 이동 | WASD |
| 화면 오른쪽을 끌기: 둘러보기 | 마우스로 화면 오른쪽 끌기 |
| 점프 / 부수기 / 놓기 버튼 (꾹 누르면 반복) | 스페이스 / Q / E |
| 아이템 바 칸 누르기 | 1~6 |
| 가방 버튼 | B |

## 게임 내용

- 256×256 월드, 초원·숲·사막·눈밭, 바다와 동굴, 땅속 철광석
- 낮과 밤(4분에 한 바퀴). 밤에는 좀비가 나오고, 침대에서 자면 아침이 됩니다.
- 서바이벌(블록을 모아서 사용) / 창작(블록 무한, 점프 두 번 빠르게 누르면 비행) 방식. 가방 화면에서 바꿀 수 있습니다.
- 제작: 판자·막대·제작대(가방), 제작대에서 곡괭이·도끼·삽·검(나무·돌·철, 쓸수록 닳음)·화로·침대·빵, 화로에서 철 주괴·유리·구운 고기
- 블록을 캐거나 동물을 잡으면 바닥에 떨어졌다가 가까이 가면 주워요
- 돼지, 양(고기·양털), 좀비, 해골(원거리 화살), 크리퍼(가까이 오면 몇 초 뒤 폭발), 꽃, 밀 농사, 도전 과제 14개
- 자동 저장 (브라우저 localStorage), 배경음악과 효과음(코드로 합성)
- 폰 성능에 맞춰 화질을 스스로 낮춥니다. 주소 끝에 `?quality=0`~`3`을 붙이면 고정됩니다.

## 개발용 주소 옵션

- `?seed=숫자` 같은 지형으로 시작
- `?time=0.5` 시간을 멈춤 (0 한밤중, 0.25 해 뜸, 0.5 한낮, 0.75 해 짐)
- `?debug` 콘솔에서 `__vox`로 월드·플레이어·가방 등을 만질 수 있음

## 구조

```
src/
  world.ts      블록 종류, 지형·동굴·광석·꽃 생성
  mesher.ts     구역(chunk)을 그림 조각으로 만들기, atlas.ts 블록 무늬(코드로 그림)
  chunks.ts     플레이어 주변 구역만 그리기, chunkMath.ts 구역 계산
  player.ts     이동·중력·수영·자동 점프, raycast.ts 조준
  mobs.ts       돼지·양·좀비 움직임, mobRender.ts 모양 그리기
  health.ts     체력·낙하 피해, inventory.ts 가방·제작 규칙·드롭
  crops.ts      농사, achievements.ts 도전 과제, daycycle.ts 낮밤
  audio.ts      효과음 합성, music.ts 배경음악 작곡
  quality.ts    자동 화질 조절, save.ts 저장 형식
  controls.ts   터치·키보드 입력, main.ts 모든 것을 잇는 곳
```

게임 규칙 파일(`*.ts`, 화면과 무관한 것)은 `*.test.ts`로 테스트합니다.

## 배포 (GitHub Pages)

`.github/workflows/deploy.yml`이 준비되어 있습니다. GitHub에 새 저장소를 만들어 올리면
`master`에 push할 때마다 테스트 → 빌드 → Pages 배포가 자동으로 실행됩니다.
저장소 Settings → Pages → Source를 "GitHub Actions"로 바꿔 주세요.

## 앱처럼 설치하기 (PWA)

배포된 주소에서 브라우저 메뉴의 "홈 화면에 추가"(아이폰은 공유 → 홈 화면에 추가)를 누르면
주소창 없이 가로 전체 화면으로 열립니다. 처음 접속하면 게임 파일이 폰에 저장되어 인터넷이 없어도 열립니다.
(`public/manifest.webmanifest`, `public/sw.js`, 아이콘은 `public/`에 있습니다. 개발 서버에서는 동작하지 않고 배포본에서만 동작합니다.)

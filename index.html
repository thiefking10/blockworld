움직이기 화면 왼쪽을 누른 채 끌면 걷고, 오른쪽을 끌면 둘러봐요. 한 칸 턱은 저절로 올라가요.
부수기 / 놓기 십자 표시가 가리키는 블록은 부수기를 꾹 누르고 있으면 조금씩 부서져요. 곡괭이·도끼·삽이 있으면 알아서 골라 써서 빨라지고, 돌은 곡괭이로 캐야 나와요. 놓기는 아래 칸에서 고른 블록을 놓아요.
비행 창작 방식에서 점프를 두 번 빠르게 누르면 날아요. 점프는 위로, 내려가기는 아래로, 땅에 닿으면 끝나요. 컴퓨터는 Shift로 내려가요.
가방 모은 블록으로 판자, 막대, 곡괭이, 검, 침대, 빵 같은 것을 만들어요. 도구는 쓸수록 닳아요. 고기와 빵은 눌러서 먹어요.
밤에는 좀비가 나와요. 검을 만들어 싸우거나, 침대를 만들어 밤을 건너뛰어요.
농사 잔디를 부수면 가끔 밀 씨앗이 나와요. 풀이나 흙 위에 심으면 자라서 밀이 돼요.
화면이 작다면 왼쪽 위 전체화면 버튼을 눌러요. 아이폰은 사파리 공유 버튼 → 홈 화면에 추가로 열면 주소창 없이 열려요.
도전 버튼에서 해 볼 만한 일을 확인해요. 컴퓨터에서는 WASD, 스페이스, Q(부수기), E(놓기), 1~6, B(가방)를 써요.
